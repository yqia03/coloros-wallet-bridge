# 钱包快捷桥使用说明

[返回项目首页](../README.md) · [English introduction](../README.en.md)

## 安装与启用

从 [Releases](https://github.com/yqia03/coloros-wallet-bridge/releases/latest) 下载 APK，在手机上打开安装。无需连接电脑、root 或 ADB 授权。

保留原厂“双击电源键打开钱包”设置和 OPPO 钱包应用。打开「钱包快捷桥」，先测试 Google 钱包能正常打开，再按应用提示开启无障碍服务，确认“无障碍：已连接”后启用自动跳转。

如开启无障碍时出现“受限制的设置”，检查“设置 → 应用 → 钱包快捷桥 → 更多”中是否提供“允许受限制的设置”。具体入口因系统版本而异。[Google 官方说明](https://support.google.com/android/answer/12623953?hl=zh-SG)

启用后先在已解锁状态测试，再测试自己的锁屏方式。锁屏时仍须通过系统正常验证；程序不会收集锁屏密码。

## 校准识别页面

如果双击仍停在 OPPO 钱包：

1. 打开快捷桥，确认无障碍已连接，点击“开始 60 秒校准”。自动跳转会暂停。
2. 在 60 秒内双击一次电源键，等 OPPO 钱包出现；如果要求解锁，正常解锁。
3. 手动回到快捷桥，点击“结束校准并选择页面”。
4. 从记录中选择对应页面，确认保存。
5. 重新点击“启用自动跳转”并测试。有多个候选时可逐个尝试，或点击“恢复预设识别页面”。

校准只保存包名和页面类名，不保存截图或页面文字。页面标识不等于按键来源，所以手动打开同一页面也可能被转发。

## 必须一直打开应用吗？

**界面不必一直打开，但服务必须保持连接。** 设置好后返回桌面，正常使用其他应用即可。实际用户报告清理快捷桥后台后会停止跳转，因此不要清理或强行停止快捷桥。

如果清理后失效，重新打开快捷桥，检查：

- “无障碍”是否显示“已连接”；没有连接时，前往系统设置检查并重新开启。
- “自动跳转”是否已开启。
- “测试打开 Google 钱包”是否成功。

如果 ColorOS 提供相关选项，可以为此应用允许后台活动，或锁定其最近任务卡片以减少被清理的机会；菜单名称和实际效果取决于系统版本。这些设置不能保证应用永不被系统停止。

重启或系统升级后也可能需要重新开启无障碍服务。当前版本不会使用 ADB 权限自动改写系统设置。

## 会实时看屏幕、很费电吗？

不截屏、录屏或做 OCR。系统在指定钱包应用的窗口状态变化时通知服务，服务只检查包名和页面类名，匹配后进行一次跳转。没有持续扫描屏幕或网络活动。

后台服务需要占用少量系统资源，**耗电未进行设备测量**。可以在手机的应用耗电统计中观察实际情况。设置页面中的状态刷新在离开该页面后停止。

## 常见情况

| 现象 | 可以检查什么 |
| --- | --- |
| 校准列表为空 | 服务是否连接；是否在 60 秒内触发原厂钱包；固件是否使用了不同包名 |
| 跳转前闪过 OPPO 钱包 | 这是通过原厂入口转发可能出现的现象 |
| 系统询问是否允许打开 Google 钱包 | 阅读系统对该应用跳转的提示后决定是否允许 |
| 手动打开 OPPO 钱包也跳转 | 当前选择的页面被匹配了；先暂停快捷桥 |
| 打开 Google 钱包后仍不能支付 | 支付能力由 Google 钱包本身决定，本工具只负责打开应用 |
| 反复跳转或选错页面 | 先暂停，恢复预设或重新校准；在 Issues 中提供诊断信息 |

## 反馈与诊断

点击“复制诊断信息”，到 [Issues](https://github.com/yqia03/coloros-wallet-bridge/issues) 提交，并补充失败发生在亮屏还是锁屏、是否刚清理后台，以及是否有系统弹窗。

应用生成的诊断包含机型、系统版本、服务状态和校准页面标识，不包含卡片数据。反馈无需银行卡号、账户信息或锁屏密码。

已收到国行 Find X9 未 root 的成功跳转反馈，但精确 ColorOS 版本与各种锁屏、重启组合尚未完整记录。其他设备仍需测试。

## 暂停与卸载

在应用内点击“暂停自动跳转”，或在系统设置中关闭无障碍服务即可停用。卸载应用会删除它的配置；本工具没有修改原厂双击电源键设置。
